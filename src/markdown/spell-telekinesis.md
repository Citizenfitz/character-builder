_Telekinesis_ allows the caster to magically move objects up to 200 lb. per level . _Telekinesis_:

- Can only affect one object at a time.
- Can be move objects up to 60' per round
- Allows unwilling creatures to make a WIS-modified saving throw to escape the effect.
- Allows the caster to telekinetically fight with weapons using their normal combat talent.
- Can perform any task the caster could with their own hands save those requiring very fine, delicate work (picking locks, sewing, etc.).
