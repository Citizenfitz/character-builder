Character is able to perform basic medical tasks (setting broken bones, stabilizing bleeding, etc.). A successful roll:

- Stabilizes character at 0 or fewer hit points from losing more hp. See “death’s door” in the Attrition Attacks section (q.v.).
- Return 1d2 hit points that were suffered within 10 minutes of applying the talent
- Cure normal, non-magical diseases (recover in 1d6 days).
- Allows a poisoned individual a second saving throw. For fast-acting poisons this must be done within 3 rounds. For slower poisons it can be performed anytime before death. In both cases the subject will recover (with a successful save) in 10-60 minutes.

| Action                    | DC  |
| ------------------------- | :-: |
| Stabilize dying character |  8  |
| Treat common disease      | 10  |
| Treat rare disease        | 15  |
| Treat poison              | 15  |

The talent is not cumulative, ie. multiple characters with it cannot apply it at once to return multiple hit points or give more than one saving throw.
