With a successful roll a character can open locks and detect/defeat alarms and traps. For detecting alarms & traps the character must specifically state they are taking time to search for them.

| ACTION                                                                   | DC  |
| ------------------------------------------------------------------------ | :-: |
| Find/disarm simple trap (crude pit covered with brush), pick simple lock | 15  |
| Find/disarm average dungeon trap, Pick average lock                      | 20  |
| find/disarm exceptional trap, Pick exceptional lock                      | 25  |
| Open complicated safe                                                    | 35  |
