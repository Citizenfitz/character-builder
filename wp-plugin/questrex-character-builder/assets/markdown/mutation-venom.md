Thrice per day the character can deploy a venom attack using nettles, dermal excretion, stinger, bite, etc. The character must successfully hit the target in combat and the target is allowed a saving throw to avoid the effect. Roll d8 to determine which type of venom the character possesses:

| D4 Roll | Venom Type                                                                                 |
| :-----: | ------------------------------------------------------------------------------------------ |
|  **1**  | **Weakness venom**<br>affects target identically to a Ray of Enfeeblement spell for 1 hour |
|  **2**  | **Paralytic venom**<br>affects target identically to a Hold Person spell for 2d6 rounds    |
|  **3**  | **Psychotropic venom**<br>affects target identically to a Confusion spell for 1d10 rounds  |
|  **4**  | **Lethal venom**<br>inflicts continuous 1d6 damage on target for 3d4 rounds                |
