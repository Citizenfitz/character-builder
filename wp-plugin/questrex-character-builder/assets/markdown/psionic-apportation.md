This power instantly teleports the user to another location of any distance but only on the same plane of existence. The user may bring along one other creature weighing no more than 500lb. Unwilling creatures are allowed a saving throw to avoid the effect. If the location is clearly visible to the user there is no chance of error. If the user cannot directly see the location he or she must make a successful roll on the Remote Sensing Table (q.v.). Success indicates the user arrives safely. Failures are handled on the table below by rolling a d100:

| Remote Sensing DC | Fail  | Nearby |  Lost  | Disaster |
| :---------------: | :---: | :----: | :----: | :------: |
|         5         | 01-90 | 91-97  | 98-100 |    -     |
|        10         | 01-80 | 81-93  | 94-100 |    -     |
|        15         | 01-70 | 71-85  | 86-97  |  98-100  |
|        18         | 01-64 | 65-84  | 85-94  |  95-100  |
|        20         | 01-60 | 61-82  | 83-92  |  93-100  |
|        25         | 01-50 | 51-76  | 77-89  |  89-100  |

- **Fail** = Apportation expends PSP but fails to teleport user
- **Nearby** = User appears near to target. GM randomly determines location.
- **Lost** = User appears wildly off target (completely different town, middle of unknown forest, etc.). If the user was transporting other creatures they may all be separated.
- **Disaster** = Roll a 6d to see where user appears:

  - **1-4** - too high in the air (d100 feet)
  - **5-6** - inside solid space. Make an INT-modified saving throw to be shunted to the nearest vacant area. Failure indicates death.

- **x2 Stacking:** User can take up to three creatures 1,500lbs or less
- **x3 Stacking:** User can take up to six creatures of 2,000lbs or less
