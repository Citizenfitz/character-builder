_Mirage Arcana_ creates a massive shadow illusion which reshapes the terrain to anything the caster desires. (much as a _Hallucinatory Terrain_ spell). As this spell is a shadow illusion the changes are partially real and the following guidelines should be observed:

- Objects added to the terrain (i.e. a bridge over a chasm) will actually exist and can be interacted with.
- Objects removed from the terrain (i.e. a copse of trees made to seem an empty field) are not actually removed but creatures failing to disbelieve will act as if they're absent.
