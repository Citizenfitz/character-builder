With this power a user can send and receive thoughts to one intelligent creature (except undead or many mechanical intelligences) within range. Language is no barrier but creatures of limited intelligence (e.g. dogs) will be unable to comprehend complex concepts sent via _Telepathy_. Targets are allowed a WIS-based saving throw to completely negate _Telepathy_. The target's saving throw DC depends on what the user is trying to accomplish:

| User Telepathy Goal           | Target Save DC |
| ----------------------------- | :------------: |
| Scan or send surface thoughts |       17       |
| Scan deep, hidden thoughts    |       13       |
| Scan into the target’s memory |       8        |

| Modifiers                    |     |
| ---------------------------- | :-: |
| Target won't notice scanning | -3  |

- **x2 Stacking:** Telepathy may target up to 3 individuals and facilitate "party line" communication between them if the user so wishes.
- **x3 Stacking:** Telepathy may target up to 7 individuals and facilitate "party line" communication between them if the user so wishes.
