The user can project delusion illusions directly into the mind of any other intelligent creature (except undead or many mechanical intelligences). _Mental Illusions_ do not exist outside of the target's mind and cannot be seen by others or recorded on camera. The target's saving throw DC depends on what the user is trying to accomplish:

| User Illusion Goals                          | Target Save DC |
| -------------------------------------------- | :------------: |
| Cosmetic Changes to setting                  |       20       |
| Major Changes to setting                     |       17       |
| Complete changes to setting                  |       13       |
| Target no longer interacts with real setting |       8        |

| Modifiers                                  |     |
| ------------------------------------------ | :-: |
| Highly believable or target expects change | +3  |
| Highly unbelievable or unexpected          | -2  |

**Illusory attacks** (laser beams, boulders falling, etc.) inflict up to 1d6 of "damage" per level user has with Psionics (GM's prerogative on how much an attack would inflict). If this "damage" reduces their hit points below zero they pass out for 3d6 minutes. Upon waking or the power's end, all illusory damage vanishes.

**Illusory monsters** can attack and inflict "damage" that works just like that of a direct illusory attack. The monsters attack with the casters Combat Talent skill. Illusory monsters who behave unrealistically may trigger a new saving throw for the target (GM's prerogative).

- **x2 Stacking:** The power may target two creatures within range
- **x3 Stacking:** The power may target four creatures within range
