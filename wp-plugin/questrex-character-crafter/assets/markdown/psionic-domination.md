This ability allows the user to influence or subjugate a target's actions by sending them mental commands they must follow. _Domination_:

- Has no language barrier but cannot send highly complex messages as can Telepathy,
- Has no effect on non-intelligent or undead creatures, and may not function against some mechanical minds.

Targets are allowed a WIS-based saving throw to completely negate _Domination_. The target's saving throw DC depends on what the user is trying to accomplish:

| User Domination Goals                        | Target Save DC |
| -------------------------------------------- | :------------: |
| Action target is inclined towards            |       20       |
| Action target wouldn't mind doing            |       17       |
| Action target is normally against            |       13       |
| Action target is violently against           |       8        |
| Modifiers                                    |                |
| -------------------------------------------- |     :---:      |
| Target won't remember actions performed      |       -2       |
| Target will think actions was his own idea   |       -3       |
| Command is exceptionally well worded         |       +3       |
| Command is exceptionally poorly worded       |       -2       |

- **x2 Stacking:** The power may target two creatures within range
- **x3 Stacking:** The power may target four creatures within range
